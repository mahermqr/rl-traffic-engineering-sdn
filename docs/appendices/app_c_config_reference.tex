\section{Centralized Configuration Architecture}
The system's operational parameters are managed centrally by \texttt{config.py}. Configuration resolution follows strict four-tier hierarchical precedence:
\begin{enumerate}
    \item \textbf{CLI Arguments}: Explicit command-line arguments override all other layers.
    \item \textbf{Environment Variables}: System environment variables (prefixed with \texttt{SDN\_} or \texttt{RL\_}).
    \item \textbf{Configuration File}: Optional JSON file (\texttt{config.json}) in the workspace root.
    \item \textbf{Production Defaults}: Calibrated hardcoded defaults.
\end{enumerate}
